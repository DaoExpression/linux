===============================================================================
       FREEBSD VNET JAIL & INTERNAL HOMELAB NETWORK CONFIGURATION GUIDE
===============================================================================

This guide configures an isolated internal virtual network on a FreeBSD host.
Jails communicate with each other over a virtual switch (bridge0) and epair
interfaces using VNET (virtual network stack), routed through PF NAT for internet access.

Architecture Overview:
----------------------
  Physical Interface (WAN/LAN): em0 (e.g., 192.168.1.50)
  Internal Bridge (Switch):    bridge0 (Gateway: 10.0.0.1/24)
  Internal Subnet:             10.0.0.0/24

  Jails:
    1. "web"   (FreeBSD Nginx/App Server)  -> 10.0.0.10
    2. "db"    (FreeBSD Database Server)   -> 10.0.0.20
    3. "linux" (Debian/Ubuntu Linux Jail)  -> 10.0.0.30

===============================================================================
SECTION 1: HOST SYSTEM PREPARATION (/etc/rc.conf & /etc/sysctl.conf)
===============================================================================

1. Enable necessary services and virtual network modules in /etc/rc.conf:

-------------------------------------------------------------------------------
# /etc/rc.conf snippet
-------------------------------------------------------------------------------
# Enable Jails
jail_enable="YES"

# Enable PF Firewall for NAT and routing
pf_enable="YES"
pf_rules="/etc/pf.conf"

# Create virtual bridge interface for internal jail communication
cloned_interfaces="bridge0"
ifconfig_bridge0="inet 10.0.0.1 netmask 255.255.255.0 description 'Jail-Internal-Bridge'"

# Enable Linux binary compatibility (Linuxulator)
linux_enable="YES"


2. Enable IP forwarding in /etc/sysctl.conf so FreeBSD routes jail traffic:

-------------------------------------------------------------------------------
# /etc/sysctl.conf snippet
-------------------------------------------------------------------------------
# Enable IPv4 Packet Forwarding (Host acts as gateway for Jails)
net.inet.ip.forwarding=1

# Allow raw sockets in jails if needed (ping, traceroute)
security.jail.allow_raw_sockets=1


===============================================================================
SECTION 2: FIREWALL & NAT SETUP (/etc/pf.conf)
===============================================================================

Configure PF on the host to provide NAT (Network Address Translation) for
the 10.0.0.0/24 subnet and allow inter-jail traffic.

-------------------------------------------------------------------------------
# /etc/pf.conf
-------------------------------------------------------------------------------
# Interfaces & Subnets
ext_if = "em0"                  # Change to your actual physical interface
jail_if = "bridge0"
jail_net = "10.0.0.0/24"

# IP Definitions
web_jail = "10.0.0.10"

# Default Options
set skip on lo0
set block-policy drop

# NAT: Translate internal jail traffic to physical interface IP
nat on $ext_if from $jail_net to any -> ($ext_if)

# Port Forwarding (Optional): Forward port 80/443 on host to web jail
rdr on $ext_if proto tcp from any to ($ext_if) port 80 -> $web_jail port 80
rdr on $ext_if proto tcp from any to ($ext_if) port 443 -> $web_jail port 443

# Filter Rules
block all

# Pass all internal jail-to-jail and jail-to-host traffic
pass quick on $jail_if all

# Pass outgoing host & NAT traffic
pass out quick on $ext_if all keep state


===============================================================================
SECTION 3: JAIL CONFIGURATION MASTER FILE (/etc/jail.conf)
===============================================================================

This master configuration defines global settings for VNET networking and
individual configurations for each jail.

-------------------------------------------------------------------------------
# /etc/jail.conf
-------------------------------------------------------------------------------
# Global Parameters
path = "/usr/local/jails/$name";
host.hostname = "$name.home.internal";

# Exec scripts for jail lifecycle
exec.start = "/bin/sh /etc/rc";
exec.stop = "/bin/sh /etc/rc.shutdown";
exec.clean;
mount.devfs;

# Enable VNET (Virtual Network Stack)
vnet;
vnet.interface = "epair${vnet_id}b";

# Network creation and destruction lifecycle scripts
exec.prestart  = "jt=`mktemp -t jail` && devfs ruleset -s 4 load user > $jt && devfs -m /usr/local/jails/$name/dev ruleset 4 apply && rm $jt";
exec.created   = "ifconfig epair${vnet_id} create up";
exec.created  += "ifconfig bridge0 addm epair${vnet_id}a up";
exec.poststop  = "ifconfig epair${vnet_id}a destroy";

# Default devfs ruleset
devfs_ruleset = "4";

#------------------------------------------------------------------------------
# 1. FreeBSD Web Jail
#------------------------------------------------------------------------------
web {
    $vnet_id = "10";
    exec.start += "/sbin/ifconfig epair10b inet 10.0.0.10 netmask 255.255.255.0 up";
    exec.start += "/sbin/route add default 10.0.0.1";
}

#------------------------------------------------------------------------------
# 2. FreeBSD Database Jail
#------------------------------------------------------------------------------
db {
    $vnet_id = "20";
    exec.start += "/sbin/ifconfig epair20b inet 10.0.0.20 netmask 255.255.255.0 up";
    exec.start += "/sbin/route add default 10.0.0.1";
}

#------------------------------------------------------------------------------
# 3. Linux Jail (Ubuntu / Debian using Linuxulator)
#------------------------------------------------------------------------------
linux {
    $vnet_id = "30";
    host.hostname = "linux.home.internal";
    
    # Enable Linux System Call emulation
    allow.raw_sockets;
    sysvmsg=new;
    syssem=new;
    sysvshm=new;

    # Linux-specific mounts required for Linux binary compatibility
    mount.fstab = "/etc/jail.fstab.linux";

    # Exec commands tailored for Debian/Ubuntu init system
    exec.start = "/bin/true"; # Or use linux userland init: "/etc/init.d/rc 3"
    exec.stop = "/bin/true";

    # Network setup executed on the host inside the jail's vnet namespace
    exec.poststart += "jexec linux ifconfig epair30b 10.0.0.30 netmask 255.255.255.0 up";
    exec.poststart += "jexec linux route add default gw 10.0.0.1";
}


===============================================================================
SECTION 4: LINUX JAIL FSTAB SETUP (/etc/jail.fstab.linux)
===============================================================================

Linux userland requires pseudo-filesystems (linprocfs, linsysfs, devfs) to function.

-------------------------------------------------------------------------------
# /etc/jail.fstab.linux
-------------------------------------------------------------------------------
devfs           /usr/local/jails/linux/dev      devfs           rw,ruleset=4 0 0
tmpfs           /usr/local/jails/linux/dev/shm  tmpfs           rw,mode=1777 0 0
fdescfs         /usr/local/jails/linux/dev/fd   fdescfs         rw,linrdlnk  0 0
linprocfs       /usr/local/jails/linux/proc     linprocfs       rw           0 0
linsysfs        /usr/local/jails/linux/sys      linsysfs        rw           0 0


===============================================================================
SECTION 5: PROVISIONING STEPS
===============================================================================

1. Create directory structures:
   $ sudo mkdir -p /usr/local/jails/web
   $ sudo mkdir -p /usr/local/jails/db
   $ sudo mkdir -p /usr/local/jails/linux

2. Extract FreeBSD base userland for FreeBSD jails:
   $ sudo fetch https://download.freebsd.org/releases/amd64/amd64/14.0-RELEASE/base.txz
   $ sudo tar -xf base.txz -C /usr/local/jails/web
   $ sudo tar -xf base.txz -C /usr/local/jails/db

3. Provision Linux userland (Debian/Ubuntu example using debootstrap):
   $ sudo pkg install debootstrap
   $ sudo kldload linux linux64
   $ sudo debootstrap bookworm /usr/local/jails/linux http://deb.debian.org/debian

4. Configure DNS resolvers for jails:
   $ echo "nameserver 1.1.1.1" | sudo tee /usr/local/jails/web/etc/resolv.conf
   $ echo "nameserver 1.1.1.1" | sudo tee /usr/local/jails/db/etc/resolv.conf
   $ echo "nameserver 1.1.1.1" | sudo tee /usr/local/jails/linux/etc/resolv.conf

5. Start the network & jails:
   $ sudo service pf restart
   $ sudo service netif restart
   $ sudo service jail start

===============================================================================
SECTION 6: TESTING INTER-JAIL COMMUNICATION
===============================================================================

1. Ping Linux jail from Web jail:
   $ sudo jexec web ping -c 3 10.0.0.30

2. Ping Database jail from Linux jail:
   $ sudo jexec linux ping -c 3 10.0.0.20

3. Verify outbound internet connection from Linux jail:
   $ sudo jexec linux curl -I https://www.freebsd.org
